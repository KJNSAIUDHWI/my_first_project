# 使用说明

## 环境与依赖

已验证环境为 Windows x64、Python 3.13（支持 Python 3.10+）。完整本地检测默认在 CPU 上运行；手写填空转录需要联网并配置视觉大模型 API 密钥。

在项目根目录创建独立虚拟环境并安装依赖：

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

如需在国内加速下载，可附加清华镜像参数 `-i https://pypi.tuna.tsinghua.edu.cn/simple`；如需 GPU 训练（CUDA 12.4 示例），可先安装对应版本的 PyTorch：

```bat
pip install --extra-index-url https://download.pytorch.org/whl/cu124 torch==2.6.0+cu124 torchvision==0.21.0+cu124
pip install -r requirements.txt
```

Paddle 印刷题号通过 `onnxruntime` 直接推理，无需安装完整的 PaddlePaddle。不要同时手动安装多个提供 `cv2` 的 OpenCV 发行包。

## 下载与恢复部署权重

自训推理权重包（**45.7 MB** 单文件，AES-256 含文件名加密）托管在 [GitHub Releases (`v2026.11.27`)](https://github.com/KJNSAIUDHWI/my_first_project/releases/tag/v2026.11.27)，官方 `PP-OCRv6` 印刷题号模型（约 73 MB）由脚本直接从百度飞桨官方源下载。

在项目根目录执行一键准备脚本：

```bat
python tools\下载权重.py
```

脚本会自动完成：
1. 从百度飞桨官方源下载并校验 `PP-OCRv6` 到 `models/pretrained/PP-OCRv6_medium_rec_onnx/`；
2. 从 GitHub Releases 下载 `autograde_weights_v20261127.7z` 到 `weights/` 并校验 SHA256；
3. 提示输入解压密码并调用本机 7-Zip 解压 6 个纯推理模型至 `models/`。

> 自训权重不随代码开源，如需获取解压密码请联系项目维护者邮箱：`lkqxsdggyx@gmail.com`。
> 如命令行访问 GitHub 较慢，可先在浏览器从 Releases 页面手动下载 `autograde_weights_v20261127.7z` 放入 `weights/` 目录，再运行 `python tools\下载权重.py` 或在桌面工作台点「输入密码解压加密权重」。校验值与完整清单见 [SHA256SUMS.txt](../weights/SHA256SUMS.txt)、[部署清单](../weights/部署清单_20261127.json) 与 [权重说明](../weights/说明.txt)。

## 配置视觉大模型 API

项目采用统一 OpenAI 兼容视觉接口，内置 **豆包（火山方舟） / 小米 MiMo / DeepSeek / 通义千问 / 智谱 / 自定义中转站** 预设。有两种配置方式（任选其一）：

- **方式一（推荐）**：启动工作台后点击右上角 **「⚙ 大模型 API」**，选择运营商、填入 Key 与模型名，点击「测试连通性」通过后保存（自动写入 `.env`）。
- **方式二（手动编辑 `.env`）**：复制根目录 [`.env.example`](../.env.example) 为 `.env` 并填写：

```dotenv
VLM_PROVIDER=doubao
ARK_API_KEY=your_ark_api_key
# 如切换其他 OpenAI 兼容服务或中转站：
# VLM_PROVIDER=custom
# VLM_BASE_URL=https://your-endpoint/v1/chat/completions
# VLM_MODEL=your-vision-model
# VLM_API_KEY=your_api_key
```

系统环境变量优先于 `.env`，`.env` 已加入 `.gitignore`。默认火山方舟模型为 `doubao-seed-2-1-lite-260915`（关闭思考模式，图片精度 `high`，非流式返回），接口封装与提示词见 `pipeline/common/recognition_api.py`。

## 运行识别

### 方式 A：通过桌面工作台（推荐）

双击根目录 `自动改卷工作台.exe` 或运行 `python tools/工作台.py serve --open`，按界面引导完成「环境自检 → 录入新数据 → 自动识别 → 审阅与协作」。

### 方式 B：通过命令行直接跑批

输入目录放置 `.jpg`、`.jpeg` 或 `.png` 图片，逐张按页处理（不递归扫描子目录）：

```powershell
python -B pipeline/run.py --recognize --input "../papers" --out "../grading-results/run-001" --concurrency 4
```

| 参数 | 用途 |
|---|---|
| `--input` | 本地扫描图片目录；公开克隆仓库后需显式指定 |
| `--out` | 本批输出目录，建议每批使用独立新目录 |
| `--working-images` | 图片已转正，保留原像素，仅检查方向 |
| `--concurrency` | API 任务并发数，1 至 8，默认 4 |
| `--detect-only` | 仅执行本地检测、涂卡识别与拼图，不调用视觉大模型 API |

同一批输入、代码与模型保持一致时，可重复使用相同命令与输出目录断点续跑（已成功缓存的 API 图块不会重复扣费）。

## 可视化审阅与局域网协作

```powershell
python -B tools/识别验收.py --dir "../grading-results/run-001" --port 8904 --lan
```

在浏览器访问 <http://127.0.0.1:8904/>（同局域网协作者访问 `http://<主机IP>:8904/`）：

- **零遮挡布局**：左侧整页原卷支持滚轮缩放与中键/右键/空格拖动平移，右侧浮动答案卡片与卷面连线对齐。
- **低置信度精确框定位**：按 `L` 逐个定位低置信度框（`低置`），弹窗标明具体来源模型/规则，确认无误可点 `✓ 信任无误`。
- **原地改答案与原地调框**：点答案卡片直接改字；按 `E` 原地切入调框模式修正检测框，按 `Alt` 暂隐叠层核对原字。
- **提交与协同**：按 `D` 保存提交当前页并自动跳下一张；支持页级领卷锁与 3 秒实时同步，详见 [审阅与协作指南](审阅与协作指南.md)。

## 输出与常见问题

输出目录包含 `results.json`、输入与模型清单、页面图片、裁图、拼图、API 响应缓存与人工审阅修改记录。

| 现象 | 处理方式 |
|---|---|
| 缺少模型文件 | 运行 `python tools\下载权重.py` 检查官方 `PP-OCRv6` 与 Release 权重包是否已解压至 `models/` |
| 缺少 Python 依赖 | 执行 `pip install -r requirements.txt` 或在工作台环境自检页点击一键测速补包 |
| 未找到可识别的答题区 | 当前支持选择题、填空及实验题；检查原卷版式、方向和图片清晰度 |
| 未配对 / 题号推算告警 | 按 `L` 定位该题框，核对印刷题号或按 `E` 调整题号框/选项框位置 |
| 未检出选中项 | 对照原图检查是否未作答或涂痕较浅，可直接点击卡片修正答案 |
| HTTP 401 / 403 | 打开工作台「⚙ 大模型 API」检查密钥、Base URL 与模型权限并测连通性 |
| 账号用量 / 费用限制 | 在对应平台控制台检查额度，解决后用相同命令续跑即可复用已成功缓存 |
| 公式显示失败 | 页面保留原始 LaTeX 转录并提示原因；首次启动验收页会缓存 KaTeX 资源，无外网时可先看原文 |
