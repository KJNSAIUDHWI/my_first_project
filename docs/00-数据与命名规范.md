# 数据与命名规范

只定义长期约束；当前版本和临时限制见01，命令见05，实现入口见02。

## 1. 文件放在哪里

| 目录 | 职责 |
|---|---|
| data | 工作图、人工日志、身份和固定名单；原始扫描是否留存须看当前清理记录 |
| models | 官方基础权重、永久候选、部署索引、评估报告 |
| train | 训练期间保存独立快照及现场；用户授权收尾后保留权重、最小来源记录和清理索引 |
| pipeline / tools | 共用实现 / 操作入口 |
| docs | 规则、当前状态、导航、原理、环境、操作、交付状态和历史索引 |


项目整理沿用用户现有目录；新建、改名或迁移项目文件夹须先获得明确同意，不以代码整理或文档维护为由自行扩展目录树。文档在现有docs内维护，数据与代码沿用各自既有位置。

临时脚本、调试日志、截图、改前备份放 `D:/temp/<AsiaShanghai-YYYY-MM-DD-HH-mm>_codex_<用途>/`，不混入正式目录，不动桌面777。改现有文件前备份；用户对本次操作明确另有要求时按用户决定执行。删除、移动先核实绝对目标和用途，不按“旧”“大”推断可以删除。

## 2. 名字怎样保留来源

新导入的原始扫描可放data/raw，命名 `<年>.<月>.<序号>.<学科>.jpg`。编号跨学科连续、位数按批次最大张数确定，正反面分别编号，不加_A/_B。导入时原图只复制、不覆盖；用户明确授权后可清理原始扫描副本，来源信息仍由manifest和锁定的sampling保留。本次原始输入已清理，M1工作图与标签独立保留；不得因raw缺失自动删除工作数据。

学科名用物理、数学、地生、政史、语文、英语、化学；原生物/地理合入地生、历史/道德与法治合入政史，subject_original保留原科目。

裁图保留父页和区域：`2026.7.001.物理.选择题区.jpg`，同类多个框加`.2`、`.3`；下一级可用`.大题1`。图片与日志按名对应，换图必须换名，不允许同名改像素；看图旋转不等于像素已转正。不要求图片/日志指纹、浏览器绑定或补签。

run目录：`train/<模块>_<YYYYMMDD>_<HHMMSS>_<用途>/`。永久候选：`<模块>_<YYYYMMDD>_<两位序号>_<用途>.pt`，数字/涂黑前缀为digit_cnn/choice_cnn，同日前缀序号递增，由登记模块生成。旧v版本号放用途；用途具体，不用“最新版”。

部署别名、官方预训练名称、训练现场best/last/initial和故障捕获文件按角色保留。基础权重放models/pretrained；对比放models/对比。历史改名表models/weight_renames.json负责旧路径追溯，不修改历史日志来伪装当时名称。

## 3. 各类数据保存什么

| 模块 | 输入 | 工具类别 |
|---|---|---|
| m1 | 转正整页 | 姓名学号0、选择题区1、填空题区4 |
| m2 | 选择题区 | 题号2、选项3 |
| m3 | 填空题区 | 大题框5、大题号6 |

M3大题框包含题号、分值说明、各小题和完整作答内容；另标大题号，可重叠。模型导出类别转成连续编号，不混用工具编号。

检测库data/<模块>包含images、log、manifest.csv、splits.csv，progress.csv仅状态缓存；旧dataset/labels不是现行标签源。用户授权去重后，旧dataset中与工作图SHA一致的图片副本和生成缓存已删除，标签保留；后续训练必须重新冻结独立快照。manifest保留new_name/batch/subject/source/orig_name/session/page/dup_of/has_label，splits保留new_name/split/stage/group/subject_original。

数字源库data/digit、digit_legacy：labels.csv定位file/label/split/stem，图片一般在images/train、images/val。数字0为非数字、1至60为题号；旧35类模型兼容，不代表覆盖全部类别。digit_extra的位置推断默认不准入。

涂黑源库data/choice：images每行一张PNG，名为<stem>_<三位行号>；manifest保留父图、行号、框等来源。标签为A至F组合；空值不能擅猜，n_opts=6仅表示上限，不表示实印六项。

### CNN数据目录怎样区分

增量分别放data/digit/increments/<批次>和data/choice/increments/<批次>。batch.json保存来源、父页身份、预测模型与完成状态；未完成或enabled=false批次不准入。不覆盖旧库，不把verify/API输出另算一套样本。旧记录和旧父图日志只追溯，不递归合并进当前日志。

源CSV负责定位与来源，当前逐图日志决定标签。退休批次避免重复准入，不能仅按父页名删除不同裁图。重裁新建批次，已有人工审核时禁止自动替换。

## 4. 审核怎样才算有效

人工日志是唯一标签事实源，每图/每行一个log；有同名.log时不再读旧.jsonl，不递归读归档。事件包括预标注、审核、特殊、撤销审核、旋转、调整框、倾斜校正、旧记录。预测、CSV缓存、API建议都不是人工真值。旋转、维护性调整不冒充审核。

检测审核：改框暂存，A/D提交并切图，末张也提交；左右箭头仅浏览。分类子集固定，保存后显示最新标签但不移出原子集；主动刷新分类/返回全部先保存草稿再重分组。以最终框对最后预标注判断正确/修改，曾改过不永久归修改。失败保留草稿，不假报成功。仅回看不重复记账，特殊图须取消审核后由用户重新提交。

数字/涂黑可启用用户“划过即确认”：真实鼠标经过完整显示且已加载的图才提交，可关闭/撤销，加载滚动不自行确认。代理不得代审。换页优先复用当前页，必须新开时保护草稿，只关闭本工具被替代页。界面、日志、报错使用中文。

特殊样本按用户处理决定准入；未处理/待确认不训练，也不卡整批。涂黑changed获准纳入时权重2.0，illegible排除且不作负样本。模型与手标不一致先查图，由用户修源日志，不自动按预测改标、不回写冻结快照。

审核功能测试使用D盘临时假库/副本，禁止对正式data写测试事件。

## 5. 哪些数据可以进入训练

split为train/val/test/exclude，empty_test用于已审空页误检回归。stage表示增量阶段。正反面、重复扫描及裁图继承父页group，不能跨训练验证。身份优先查m2/m1 splits；digit_legacy无法对应父页时用旧记录分区兜底，不按CSV猜。sampling锁定，不重抽补数。

历史已确认的源数据例外继续有效：2026.10.2192.语文.选择题区因上游裁错排除；2189.语文.选择题区.2仅选项底边裁回图内后准入，不能扩展为自动修其他边。

检测按显式stage累计准入；subset是本批必须核对名单，不把累计范围缩成子集。未审停止；明确暂缓可用deferred.csv记new_name/stage/reason/decision，已审后须更新。特殊须明确exclude；skip-invalid只排除留据的坏训练标签，不跳未审或坏验证。

验证基线以yolo_snapshot.VALIDATION_BASELINES为入口：M1固定147、M2固定115，固定身份与指纹必须保留；本次训练现场清理后由各自data/m1、data/m2目录下validation_baseline.json的独立名单登记读取，对应工作图仍保留，不要求历史训练快照图片副本存在。M3下一轮冻结前纳入全部普通已审合法val，validation_baseline.csv及JSON登记数量/SHA/父页/学科，旧名单保留。约一成仅参考，不强凑、不随机改父页身份。训练中快照不变；比较必须在同一名单重评旧模型。

CNN新val/test仍预留，固定旧验证不变；增量未审、撤销、未处理特殊跳过，旧digit未审报错。英语专项实验还须排除与val同raw页的其他训练区域，两架构使用相同名单；专项候选不能替换通用部署。

每轮独立dataset_snapshot：检测保存selection.csv、train_list/val_list、labels和data.yaml，run下snapshot_audit记排除/暂缓/裁剪；CNN保存selection.json。只冻结名单与标签，不复制图片；读取本run快照，不能用共享dataset，旧run缺审计不补造。实际参数、起点、数值保护和退出结果在run留据。

导出框每轴允许出界不超过max(1%,2px)，只裁导出标签；非有限、非法类别、无面积、超限报错。M3已获源框确定性裁回图内授权：保留修前记录、类别/框数/审核事实，追加维护事件；无交集或类别错误须人工，不靠裁剪猜修。

## 6. 裁图与结果怎样解释

裁图从转正工作图取坐标，不套用未转正raw。M2 cascade裁图先过滤宽高<16框，再核对姓名/选择/填空三类数量；不符整页舍弃，特殊、空页、无选择区域不产M2图，不以人工框兜底。数量相同不证明覆盖正确；裁图保留来源、身份和舍弃清单，不覆盖旧产物。

报告注明版本、日期、样本范围、单位与来源；训练回测、选模验证、独立测试分开。高IoU不保证整题内容完整，历史单科成绩不证明跨科泛化。权重检查、训练完成、用户接受效果、同意部署是不同事实。

用户授权的训练现场收尾可删除快照、日志、图表和故障输入，但须保留模型权重、训练参数、候选/部署来源、成绩、退出状态及清理清单；固定验证身份须先独立留存，不得重抽。清理后不能宣称能完整复现或恢复原训练。

成功候选永久留档，部署须用户明确同意，索引只指models内永久文件且候选来源run一致。停止、失败不改报成功；精简检查点保留参数/精度/epoch/保护事实，删除优化器后不得声称原状态恢复。清理读取compaction/pruning记录，不推断旧best/last仍在。

历史build_dataset、build_snapshot、CNN旧构建器及补多选区入口停用，不以force绕过。数值异常保留现场，不填零掩盖、不关闭保护。

## 7. 文档怎么维护

| 文档 | 只回答什么 |
|---|---|
| README | 从哪里开始 |
| AGENTS | 代理怎样协作、记录和验收 |
| 00 | 什么长期允许、禁止、必须 |
| 01 | 现在是什么状态、受什么限制、缺什么 |
| 02 | 功能和证据到哪里找 |
| 03 | 方案为什么这样设计 |
| 05 | 通用操作怎样执行 |
| 06 | 某阶段发生过什么，到哪里追溯 |

规则只在一处定义；原理不放命令/接口字段，通用操作不放某版故障经过、具体批次配方或临时绝对路径。这些放run/报告；只有影响下一步的摘要进入01。新建专题文档须有独立长期用途，不为每次修复另建报告。

01仅由写快照工具更新，结构3不使用全局S/D/Q编号，不携带关闭事项。普通更新覆盖当前状态；长期决定进入相应规则，阶段变化用--event写短摘要，交接用--handoff保存按内容指纹命名的独立快照。06由事件生成索引，不嵌全文；事件与旧档不改写，纠错追加说明。旧档只在追溯时读，不加载进每轮接力。

目标是接手能迅速做事，不按字节强删事实。01超过约5000汉字时检查是否夹带证据原文或已完成过程；这是维护提醒，不是截断/丢事实的硬限制。写入前核对限制去向和事实，工具只检查结构、并发和归档完整性。
