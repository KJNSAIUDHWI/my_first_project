# 数据与命名规范

这份文档定义长期规则：文件放哪、怎样命名、审核怎样才有效、什么数据能训练。当前批次的数量、模型版本和用户决定写在[01](01-接力记录.txt)；具体命令看[05](05-迭代操作.md)。

## 1. 文件放在哪里

| 目录 | 保存什么 |
|---|---|
| `data/` | 原始扫描件、工作图片、审核记录、固定名单 |
| `models/` | 基础权重、部署权重、永久候选和对比结果 |
| `train/` | 每轮训练的数据快照、参数、日志和检查结果 |
| `pipeline/` | 图片处理、模型训练及共用代码 |
| `tools/` | 操作入口、审核页面、监控与验证工具 |
| `docs/` | 长期规则、当前进度、导航、原理、操作及历史 |

项目不是Git仓库，修改现有文件前先备份。临时脚本、截图、诊断结果、临时日志和备份统一放在本次专属目录，时间按上海时区：

```text
D:/temp/<YYYY-MM-DD-HH-mm>_codex_<用途>/
```

项目内不建tmp、misc等临时目录，D:/temp根目录不散放文件。正式数据与长期代码仍放项目对应目录，不依赖临时目录运行。删除或覆盖前核实目标并备份，不删除历史权重。桌面777不读不改，也不作为新数据来源。

## 2. 名字怎样保留来源

### 原始扫描件

母本放 `data/raw/`，不按学科分子目录。命名为 `<年>.<月>.<序号>.<学科>.jpg`，例如 `2026.7.001.物理.jpg`。

- 序号跨学科连续，位数按批次最大张数确定；正反面各占一个编号，不加_A或_B。
- 学科使用物理、数学、地生、政史、语文、英语、化学。地理/生物归地生，历史/道德与法治归政史，原学科写入 `subject_original`。
- 原图只复制，不移动、不覆盖；来源和编号按清单保留，换图必须换文件名。
- 需要转正时改工作副本；sampling.csv是已锁定的抽样和来源记录，不为补新字段重写。历史指纹字段保留原值，当前审核、训练不要求补齐或更新。看图时旋转不代表图片像素已转正。

### 局部裁图

裁图保留父页名和区域名，例如 `2026.7.001.物理.选择题区.jpg`。同类第二、第三个框加 `.2`、`.3`；填空下一级可用 `...填空题区.大题1.jpg`。

名字和记录必须能追溯到raw母本及m1审核日志，不能裁完后丢失父页身份。

### 训练运行与模型权重

一次独立训练称为一个run，目录为 `train/<模块>_<YYYYMMDD>_<HHMMSS>_<用途>/`。失败后另建run，旧现场保留。

检测候选命名为 `<模块>_<YYYYMMDD>_<两位序号>_<用途>.pt`；数字和涂黑分别以 `digit_cnn`、`choice_cnn` 开头。同一前缀同日从_01_递增，由登记模块生成。用途写具体，不用“最新版2”等含混名称。每次成功训练的最终候选永久留档；同内容的历史版本和部署别名可以同时保留。

部署别名通常是 `models/<模块>/<模块>.pt`，CNN由权重登记模块规定。基础权重放 `models/pretrained/`，对比结果放 `models/对比/<模块>/`。

留档与部署分开。更换部署权重须用户同意；部署索引和候选记录只允许指向项目models内的永久权重，候选来源run必须与拟部署run一致。

训练共用固定入口，不为每轮复制脚本。遇到历史中文权重与ultralytics的兼容问题，可在本次临时目录建立ASCII名称副本并核对指纹；这不表示所有中文路径都会失败。

## 3. 各类数据保存什么

### 检测框：m1至m4

| 模块 | 输入图片 | 标注工具类别编号 |
|---|---|---|
| m1 | 转正整页 | 姓名学号0、选择题区1、填空题区4 |
| m2 | 选择题区裁图 | 题号2、选项3 |
| m3 | 填空题区裁图 | 大题框5、大题号6 |
| m4 | 填空大题裁图 | 小题号7、填空行9 |

大题框5包含各小题的完整题号、作答内容和填空行，不含大题号、标题及分值说明；大题号单独标6。界面虽有类别8按钮，但m4训练未启用，不能据此使用。导出训练集时，共用代码把工具编号转换为模型所需的连续编号。

```text
data/<模块>/
  images/       工作图片
  log/          每图一个<图名>.log（中文事件，一行一条）
  manifest.csv  图片来源
  progress.csv  可重建的审核状态缓存
  splits.csv    固定分区和父页身份
  dataset/      旧构建器留下的数据集，不作为现行训练入口
```

**日志是标签的事实来源。** 改标注应通过审核记录并重新确认，不能手改旧dataset或训练快照的标签。

需要维护表结构时使用以下字段：

| 文件 | 字段 |
|---|---|
| manifest.csv | new_name、batch、subject、source、orig_name、session、page、dup_of、has_label |
| progress.csv | new_name、status、review_count、last_review、reviewer、boxes、note |
| splits.csv | new_name、split、stage、group、subject_original |

progress的状态包括未标、已标、已审-正确、已审-修正、特殊。它是展示缓存，不能代替真实日志。

### 题号小图：digit

`data/digit`、`data/digit_legacy`通常把图片放在 `images/train`、`images/val`；`labels.csv`字段为 `file,label,split,stem`，stem表示来源图名。0表示非数字，1至34表示题号。

`digit_extra`图片直接放images，CSV中的split为train。按位置推断的标签默认不训练；允许纳入需要明确授权，不能把推断称为人工审核。

每张图一个 `data/<数字库>/log/<图名>.log`；数字库包括digit、digit_legacy、digit_extra。事件有预标注、审核、特殊、撤销审核、旧记录。labels.csv保留文件清单和来源，当前标签与审核状态读日志。旧 `legacy_reviewed.json` 已迁移成“旧记录”事件并归档，程序不再读。图片或标签改变后要重新人工确认。

### 涂黑答题行：choice

`data/choice/images/`每行一张PNG，命名为 `<stem>_<三位行号>.png`。manifest.csv记录来源、行号、题号、选项数和框坐标。

标签是A至F的组合字符串。空字符串可能表示未涂或无法读出，不能擅自猜答案。裁切使用 `pipeline/stages/choice.py` 的共用函数。每行一个 `data/choice/log/<图名>_<三位行号>.log`，审核状态从日志计算，不另存progress.csv。

## 4. 审核怎样才算有效

日志是唯一事实源，程序不另存审核依据。检测框每张图一个 `data/<模块>/log/<图名>.log`；数字和涂黑每张样本一个 `data/<库>/log/<样本名>.log`。一行一个中文事件：

| 事件 | 含义 |
|---|---|
| 预标注 | 模型先猜一遍，记模型、图片、框/答案 |
| 审核 | 用户按 A/D 离开或点“确认本图”时写入；记第几轮、最终结果和变化明细 |
| 特殊 | 正常标注表达不了的情况（学生改过答案、乱涂、不使用等） |
| 撤销审核 | 退回未审 |
| 旋转 | 只是看图旋转，图片本身没转 |
| 调整框 | 图片转正等操作后框跟着变，不算审核 |
| 倾斜校正 | 校正完成记录；不覆盖框，也不当作人工审核 |
| 旧记录 | 旧日志迁移过来的历史依据，原值不改 |

- 改框、浏览、滚动都不写日志；只有审核提交成功才记一条。提交失败保留编辑，不切换图片。
- 已审图回看没变化不重复记账；有变化追加一轮审核，记修改前后。
- 检测特殊图用“取消审核”退回未审，或点“确认本图”恢复普通审核；A/D浏览特殊图不会自动替用户取消特殊。
- 判定用最终状态和最后一次预标注比：没变是预标注正确；移动/缩放/改类别/增删是人工修正。删除后撤销、新增后又删，按最终状态算。
- 不记录图片/日志哈希，不做浏览器指纹核对。图片按命名规矩使用：**换图必须换文件名，不能同名覆盖**。
- 图片加载失败或日志写入失败要明确报错，不能显示审核成功。
- 数字标签正确时直接点“确认本图”，不必先改错再改回。

特殊答题行在日志里记 `特殊` 事件。`changed` 表示学生改过答案，获准纳入时权重必须 2.0；`illegible` 表示无法识别，不纳入也不当负样本。`处理`（纳入/排除/暂缓）、`权重`、`状态`（已确认/待确认）由用户决定后写入；没有处理的特殊行不参加训练，也不因此卡住整批数据。最终准入由 `cnn_data.collect` 检查，页面统计不能代替。

## 5. 哪些数据可以进入训练

### 先有可信身份和固定分区

split区分train（训练）、val（验证）、test（独立测试）、exclude（排除）；empty_test保存已审空页，用于误检回归，不进训练标签。stage表示增量阶段：0是旧数据，1至4是锁定的新阶段。

group标记同一卷组。正反面、重复扫描及所有裁图继承同一组，不能跨训练和验证。父页身份优先查 m2/m1 的 splits；digit 旧记录无法对应父页时，用它自己记录的 train/val 分区兜底，不按 CSV 的 split 猜。m1的sampling.csv锁定抽样和编号，不因缺额或效果不好重抽；父页子集只能从既定stage/train中选择。

### 再检查本轮审核范围

检测快照显式指定stage，累计纳入该阶段及以前的训练图。`--subset`只是本批必须检查的名单，不会把累计范围缩成这一小批。

累计范围内未审就停止。用户明确暂缓的未审训练图，可列在deferred.csv，字段为 `new_name,stage,reason,decision`，并显式传入。程序核对身份、原因、决定和仍未审状态；后来审了要更新名单，不补抽凑数。

特殊检测页须有明确的 exclude 决定才能排除。`--skip-invalid` 只用于明确排除坏标签训练图，记录名单；不能跳过坏验证图或未审图。预测不能当真值，代理不能自动 review。

### 验证集保持不变

检测基线的运行名和数量以 `pipeline/common/yolo_snapshot.py` 中的 `VALIDATION_BASELINES` 为唯一权威定义。程序按旧 run 的 val 名单读取；名单缺失或数量变化应停止，不能按审核进度缩小集合。

新增预留val/test不自动加入当前验证或训练。改变名单需用户另行决定。CNN继承父页分区，也要检查group不跨训练和验证。

### 最后冻结独立快照

每轮在 `train/<run>/dataset_snapshot/` 下只写名单和标签，不复制图片：检测任务是 selection.csv、train_list.txt/val_list.txt、labels/；CNN 任务只有 selection.json。图片直接使用 data 里的原图。已有快照不覆盖。

| 任务 | 必留的快照依据 |
|---|---|
| m1/m2 | selection.csv记录图片和分区；train_list.txt/val_list.txt保存本轮图片绝对路径；labels/train、labels/val保存本轮实际使用的标签；run目录下的snapshot_audit.json记录清单、排除/暂缓/坏标签名单、验证基线和裁剪记录 |
| digit/choice | selection.json 记录源图相对路径、标签/答案、身份和分区；不复制图片，标签来自各自日志 |

训练前核对名单、分区和文件存在，不能透传参数换成别的数据源，也不能用共享旧 dataset。旧 run 缺现行审计时保留原样，不补造；需要重训时按现行规则另建。

检测训练及独立评估通过snapshot_dataset读取本run的标签，不读取或更新data里的共享labels。数字、涂黑训练通过selection.json读取冻结的标签及data源图。旧dataset、共享labels、旧日志和旧记录目录保留作历史材料，不能作为现行标签来源；有同名.log时，检测读取优先用.log，只有尚未迁移的图才回退读同级.jsonl，不递归扫描归档目录。

导出检测框时，允许每侧出界不超过“该轴1%或2像素的较大者”，只修正导出标签。错误类别、非有限数、无正面积或超限出界报错。训练参数、起点和检查结果留在run。

## 6. 裁图与结果怎样解释

`pipeline/cascade/crop.py`只生成m2选择题区，不生成m3填空裁图。执行时解析当前m1权重，记录实际路径；导入模块不解析权重、不加载模型。命令与推理参数见[05第2节](05-迭代操作.md#2-准备图片和预标注)。

输入是m1/images中已转正的工作图，坐标不能直接套到未转正raw。人工框和预测框先过滤宽或高小于16像素的框，再核对姓名、选择题、填空三类数量；任一不符就舍弃整页，不用人工框兜底。特殊页、无目标页、不含选择题区的页不产m2图。

裁图继承父页身份，留下裁图和舍弃清单，已有图片、日志、清单不覆盖。数量相同不代表位置一定准确。

报告指标须写模型版本、样本范围、统计单位、日期和结果来源。训练回测、固定验证、独立测试分别报告。历史单科成绩不代表跨学科能力；未复现的数字标为历史记录。

以下旧写入入口已停止：m1至m4的build_dataset.py、公共旧构建器、m2/build_snapshot.py、CNN的build_digit_dataset.py、build_digit_legacy.py、build_choice_dataset.py，以及tools/补多选区样本.py。不能通过force继续使用；新增素材需要合规入口，训练快照使用05中的统一入口。

- 保留所有仍有效条目，或明确关闭并说明原因。条目、关闭说明不能为空；必填节没内容写“无”。

- 写已核实的现状，不把设计、脚本存在或模拟通过写成“功能已接通”。当前状态尽量不与未决问题重复；沿用旧事实时写明日期，避免“本轮、刚刚、最新版”跨窗口后失去指代。
