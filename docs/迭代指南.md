# 模型怎么越用越好

监工负责安排活，母后负责指出哪里不对，Agent负责准备数据和训练。模型不会因为被骂了两句就进步，得把错例变成审核过的数据。

## 先分清是哪一环出了问题

| 看见的现象 | 优先检查 |
|---|---|
| 纸倒着、侧着 | 方向校正 |
| 整片选择题或填空区没找到 | M1版面分区 |
| 选择题题号、选项框漏了或串行 | M2检测及配对 |
| 实验题漏了一大块、只截到半题、重复框 | M3大题及题号检测 |
| 框完整，印刷题号读错 | Paddle题号识别 |
| 选项框正确，涂黑选项读错 | 涂黑模型及输入裁图 |
| 原始裁图完整，手写内容读错 | 豆包转录、提示词或图片清晰度 |

先看裁图，再看转录。题没完整送进去，改手写提示词也救不了漏掉的部分。

## 一轮迭代，三方各干什么

1. **母后／监工找错例。** 在识别验收页面保存反馈，保留原图、文件名和题号。多收几种情况：新题型、暗图、空白作答、涂改和不同方向。
2. **Agent准备本轮样本。** 确认要修的模块，把原图、裁图和本轮名单整理好，登记来源、父页及训练／验证分区；先生成待人工审核的预测框。
3. **人审核。** 在标注工具里补框、删多余框、调整边界，保存审核。M3的大题框要包含整道大题的题号、分值、所有小问和作答区域；大题号另有一个小框。
4. **Agent检查并训练。** 从审核记录冻结本轮独立快照，保留固定验证集，明确训练起点和参数，启动训练监控。
5. **新旧一起比。** 用同一批图、同一套人工标签比较新旧模型；同时回看旧版式，确认修好新卷时没有把旧卷搞坏。
6. **监工看完再换。** 先给出新旧可视化和指标，经用户明确同意后切换部署，旧权重保留。

当前没有“新试卷文件夹一键变训练集”的完整导入向导。Agent需要核查并落实导入、分区、M3裁图和审核名单；不能把识别报告里的裁图直接算成审核好的训练数据。公开仓库也不附带作者的训练集、固定名单和逐图日志。

## 人工改框要用什么

维护者先用 `tools/标注工具/serve.py` 启动本轮指定模块、指定名单，再把页面交给审核的人。不要直接双击默认启动脚本来审核M3，那可能打开默认的M1库。

| 操作 | 方法 |
|---|---|
| 画新框 | 先点页面对应类别，再按住左键拖动 |
| 调整框 | 左键选中，拖框内移动，拖边角调整大小 |
| 删框 | 右键点框，或选中后按 Delete |
| 放大／平移 | 滚轮缩放，右键拖动平移 |
| 撤销／重做 | Z／Ctrl+Y |
| **保存审核并切图** | **A或D，最后一张按D也会保存** |
| 只浏览前后图 | 左右箭头，不等于提交审核 |
| 查看当前帮助 | H |

改框时页面会暂存，记得提交。保存失败时保留页面和草稿，把报错交给维护者。

题号和涂黑另有审核工具；它们与识别验收是不同页面。**识别反馈保存在这次结果里，训练审核保存在数据日志里，两者不会自动互相覆盖。**

## 工具都在仓库里

| 工具 | 入口 |
|---|---|
| 看原卷、核对识别、记录问题 | `tools/识别验收.py` |
| M1／M2／M3画框审核 | `tools/标注工具/serve.py` |
| 数字题号审核 | `tools/数字审核/serve.py` |
| 涂黑答案审核 | `tools/涂黑审核/serve.py` |
| 冻结快照、训练、查状态、部署 | `tools/迭代.py` |
| 看训练进展 | `tools/训练监控/serve.py` |
| 查部署权重路径及SHA | `tools/权重索引.py` |

具体命令、数据要求和Agent接手顺序见[Agent维护指南](Agent维护指南.md)。加密包是**部署权重**，不含整套训练数据和全部训练底座；只下载仓库可以准备识别环境，要继续训练还需要本地审核库或自行建立的数据集。
