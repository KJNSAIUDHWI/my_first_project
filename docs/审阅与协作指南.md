# 审阅与协作指南

本指南面向参与日常看卷、答案纠错与框位修正的所有协作者（支持局域网多人同时审阅）。页面右上角均内置交互式 **`? 新手教程`**，首次进入可跟随聚光灯导览快速上手。

## 加入协作

- **主机端**：双击项目根目录的 `自动改卷工作台.exe`（或执行 `python tools/工作台.py serve --open`），完成试卷导入与自动识别后，点击「人工复审（核对答案 + 调框）」进入审阅页（默认端口 `8904`）。
- **其他协作者（免安装）**：同一局域网下的电脑或平板，直接用浏览器打开主机控制总览展示的网址（如 `http://192.168.x.x:8888`），填写称呼后即可查看进度、点击任务自动领卷，系统内置页级动态领卷与 5 分钟租约锁，不会与他人撞车。

## 审阅与纠错流程

进入审阅页后，左侧为无级缩放的原卷画布，右侧边栏浮动展示对应题目的答案卡片（零遮挡设计）：

1. **优先看低置信度提示（`低置`）**：
   - 左侧列表中的 `⚠ N低置` 标记表示该页有 N 处**低置信度**识别结果。
   - 按 **`L`** 键（或点击顶栏低置信度定位按钮），画布会自动缩放并脉冲定位到对应题目框，同时标明触发原因与来源模型/规则（如 `题号OCR(PP-OCRv6)`、`涂卡识别模型(CNN)`、`手写转写大模型(VLM)`、`M1/M2/M3标框模型(YOLO)` 或 `几何连续性规则推算补全`）。
   - 核对后若识别无误，直接点 **`✓ 信任无误`** 即可消除告警；有误则直接修改答案。
2. **修改识别答案**：
   - 直接点击右侧卡片或答案项即可原地编辑选择题选项或填空转录内容；点击空白处自动关闭编辑弹窗。
3. **原地修正错框（按 `E`）**：
   - 发现题目漏框、截半或框歪，直接按 **`E`** 切换至调框模式，在原卷上拖拽/增删检测框（右键短按 `<5px` 可删框），改完按 `E` 返回审阅视图。
4. **保存并翻页（按 `D`）**：
   - 确认当前页核对完成后，按 **`D`** 保存提交并自动跳转到下一张未审试卷；多人协同状态每 3 秒自动同步。

### 常用快捷键

| 操作 | 快捷键 / 鼠标 |
|---|---|
| 放大 / 缩小原卷 | 滚轮缩放 |

## 问题反馈规范

遇到模型系统性错例需要反馈给维护者迭代时，记录清楚 **批次、文件名、题号与具体现象** 即可，例如：

> 批次 `20261127_物理`，第 3 张第 21 题只框到了后两问，前两问漏框。
> 第 16 题原图手写“摩擦起电”，大模型转录有误。

## 审阅结果与模型迭代边界

- 审阅页中提交的答案修改会保存到当前批次结果目录中，**不会直接篡改训练数据集**；
- 如需让检测或涂卡模型在后续批次中真正提升，需要维护者按 [迭代指南](迭代指南.md) 将错例样本归档审核、冻结快照、重新训练并对比验收后再切换部署权重。
- 当前支持选择题、填空与实验题识别核对；含图片/示意图的小题按当前规则整小题标记「舍弃」。手写裁图与检测到的身份区裁图会发送给已配置的视觉大模型 API，若学校或项目要求隐藏敏感信息，请先联系维护者调整流程。
