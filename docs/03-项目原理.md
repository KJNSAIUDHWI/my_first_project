# 项目原理

这份文档解释自动改卷的整体方案。想执行任务，请读[操作手册](05-迭代操作.md)；想知道哪些环节目前可用，请读[当前进度](01-接力记录.txt)。下面描述的是完整设计，不代表全部已经接通。

## 1. 从扫描图片到每题得分

自动改卷依次解决四个问题：图片是否摆正、答案在哪里、写了什么、应该得几分。

```text
扫描答题卡
  → 摆正图片
  → m1：找到姓名学号区、选择题区、填空题区
      ├─ 姓名学号区 → 读取身份信息
      ├─ 选择题区 → m2：找到题号和选项
      │              → 配对 → 识别题号和涂黑组合 → 得到选择题答案
      └─ 填空题区 → m3：找到大题及大题号
                     → m4：找到小题号和填空行 → 读取填空答案
  → 对照标准答案与评分规则
  → 每题判分，汇总成绩
```

m1至m4是四级区域检测模块，负责回答“在哪里”。题号和涂黑识别负责回答“是什么”。评分还要使用标准答案与评分规则。因此，检测到框、读出答案、算出分数，是三个不同的结果。

逐级处理能减少无关背景和版式差异，也便于单独改进一个环节。例如选择题漏答，原因可能是上游裁图漏了内容，不一定需要重训识别模型。排查时先看该环节实际收到的图片，再往前找原因。

## 2. 为什么选择题还要配对

检测出来的题号框和选项框只有位置，没有“第几题选了什么”的含义。配对程序先按空间关系把题号与答题行对应起来，再分别识别数字和涂黑组合。

题号识别使用64×64灰度小图，分为0至34共35类；0表示非数字。非数字样本在训练时随机裁成方形，减少模型靠图片宽度猜类别。

涂黑识别使用192×48灰度图，分别给A至F六个选项打分，因此能表示多选。裁图要保留涂黑内容并避开题号和“多选”等文字：通常从选项大框左边裁起；框内含题号时，从最右题号的右侧开始；题号贴近框外时还需处理文字干扰。

数据生成与识别共用裁切函数，避免训练时看到一种裁图、实际使用时却看到另一种。题号连续性可以辅助纠错，但程序按位置推断的结果仍需区别于人工确认。

## 3. 为什么用日志保存审核结论

模型预测和人工确认提供的依据不同。项目用每张图、每条答题行自己的中文日志，保存预标注、审核、特殊处理和撤销，再按事件先后恢复当前标签及状态。页面上的计数、CSV中的旧标签和模型预测，都不能代替日志里的人工结论。

改框或选择答案时，修改先留在页面；用户明确提交后才写入审核事件。提交失败就保留编辑。撤销审核会把样本退回未审；特殊样本按最后一次有效处理决定是否参加训练。

图片与日志靠文件名对应：换图必须换文件名，不能同名覆盖。当前不记录图片或日志哈希，也不做审核绑定、补签或草稿保存。各工具事件和特殊样本规则见[00第4节](00-数据与命名规范.md#4-审核怎样才算有效)。

## 4. 为什么固定分区和验证集

同一张卷的正反面、重复扫描、局部裁图往往高度相关。如果分散到训练和验证中，模型可能因为见过相似内容而得到虚高成绩。

项目为关联图片保留同一卷组身份，裁图继承父页身份，再按固定名单区分训练、验证和独立测试。新增图片不能随意随机重分，也不能因身份不清而临时指定一个分区。

验证集固定到具体图片，才能比较新旧模型。每轮只拿“这次刚好审完的图”评估，会把样本变化和模型改进混在一起。框数相同也不等于框位置准确；历史单科回测同样不能代表跨学科能力。

## 5. 为什么每轮冻结一份数据

审核数据还会继续修改，训练却必须能回答“这一轮究竟用了哪些图片、什么标签”。因此每次训练先保存独立名单和当时的标签。检测任务把标签写到本run的快照目录；数字和涂黑任务把标签或答案写入selection.json。图片直接读data原图，不另复制。

训练和独立评估读取本run的快照标签，不读共享labels里的旧导出结果。后续审核不会改写已经冻结的标签。名单、标签、训练参数、起始权重、运行日志和最终候选共同说明这一轮的来源与结果；不能直接使用共享旧dataset代替本轮快照。

具体文件和校验规则见[00第5节](00-数据与命名规范.md#5-哪些数据可以进入训练)。

## 6. 为什么训练成功还不能直接部署

训练正常退出，只说明程序跑完。权重可加载、数值有效，是产物检查；是否值得替换，还要在同一验证范围比较新旧模型，并检查各学科和本轮关心的错误。

项目把候选留档与部署分开：每次通过检查的候选永久保存，用户决定后才替换实际使用的权重。登记文件记录当前模型的路径、指纹和来源运行，避免根据文件名猜“最新版”。

微调是在已有权重上继续学习；从头训练从随机参数开始；断点恢复还需要优化器等训练状态。这三种方式不能混称。起点缺失时应停止，不能悄悄改为从头训练。

## 7. 为什么要保护数值和方向

训练中的NaN、Inf表示数值无效，可能继续损坏模型或评估结果。程序应保存出错批次和异常阶段，帮助判断原因，不能填零掩盖，也不能直接认定那批图片就是坏数据。

混合精度训练有时会出现可恢复的梯度溢出，需要与权重已经损坏区分。相关技术缩写放在下表，需要排查时再查。

图片方向影响所有下游坐标。方向模型输出的类别要映射为角度；看图时旋转，不一定改变实际像素。不同图片库对照片方向标记的处理也可能不同，比较框和裁图前必须统一。

| 术语 | 在本项目中的含义 |
|---|---|
| YOLO | 定位矩形区域的检测模型；m1、m2等使用这类模型 |
| CNN | 卷积神经网络；这里主要指题号、涂黑和方向分类模型 |
| AMP | 混合精度训练，用较低精度加速部分计算 |
| BN | 批归一化层；其中的统计值也需要检查是否被异常数值污染 |
| EXIF | 图片元数据；其中的方向标记会影响图片读取方向 |

## 8. 一轮迭代怎样改进模型

从一个具体错误出发，先保留旧模型和评估范围，再补有针对性的数据。人工审核后冻结、训练、保存候选，在相同范围比较结果，最后由用户决定是否部署。

比较中发现的新错误，再回到下一轮数据准备。这样才知道改进来自哪里，避免只反复训练而没有解决原来的问题。
