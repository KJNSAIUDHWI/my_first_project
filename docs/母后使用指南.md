# 母后使用指南

母后负责看卷、指出哪里不对。装环境、跑模型、修程序这些活，交给监工和他的 AI 苦力。

## 第一次拿到项目

在仓库页面点 **Code → Download ZIP**，解压到一个固定文件夹。里面已经有工具、说明和加密权重分卷；权重还要用7-Zip输入密码解压一次，方法见[权重说明](../weights/说明.txt)。密码单独找项目持有人拿。

请维护者按[使用说明](使用说明.md)装好环境、配置豆包密钥、启动识别和验收页面。下载完成不等于已经安装完成，当前还不是双击就能用的安装包。

日常只需要把新卷放在一个文件夹里，告诉维护者“跑这个文件夹”，然后打开他给的本机查看链接。链接里的 `127.0.0.1` 指当前电脑，换电脑后需要在新电脑启动服务。

## 看一批卷子

1. 在总览里点一张试卷。
2. 先看左边整卷：有没有一整题没框到、一个框只截了半题，或者框到了别的题。
3. 再对照右边原始裁图和答案。选择题答案也直接标在卷面上；填空题按小题、每一空排列。
4. 有问题就展开“人工反馈”，选问题类型，需要时填正确内容，点击保存。没点保存的修改仍是草稿。
5. 用“仅看未检查”接着看；重开同一批结果还能继续。

| 想做什么 | 操作 |
|---|---|
| 放大整卷 | 在原卷上滚动鼠标滚轮，或点加减按钮 |
| 看卷子其他位置 | 在原卷上按住鼠标拖动 |
| 回到整张卷子 | 点“整卷复位”，或按 F |
| 定位某题 | 点原卷上的框，或右边的“原卷定位” |
| 返回上一级 | 按 Esc：先关大图，再复位整卷，最后返回总览 |
| 看模型实际收到什么 | 点题目下方“实际拼图” |

## 发现问题，怎么说最有用

不用猜模型叫什么。把**批次、文件名、题号和现象**说清楚就行，例如：

> 这批第3张，第21题只框到了后两问，前两问漏了。
>
> 第16题原图写“摩擦起电”，结果读成了别的字。
>
> 第7题没涂答案，页面提示未检出选中项，这张是学生空着没写。

能在反馈里记录最好，也可以留截图和原文件名。整题漏掉时，用左边“整页反馈／补记漏题”。

“待核对”会注明具体原因；如果是程序错误，页面会显示失败环节和原因。把这段原因一起交给维护者，比一句“坏了”好找得多。

## 哪些算迭代

改对一次识别结果，只是保存了本次反馈，模型不会因此自动学会。维护者要把错例整理出来，请人确认框或答案，再训练、对比，最后换上新权重。完整分工见[迭代指南](迭代指南.md)。

当前支持选择题、填空和实验题的识别与核对；标准答案匹配、评分和成绩导出还没有接上。带图片或示意图的小题按现有规则整小题显示“舍弃”。手写裁图会发送给豆包转录，当前流程也会转录检测到的姓名学号区；如学校要求这些内容不能联网，请先让维护者调整流程，不能把原理动画中的本地身份识别方案当作已接入功能。
