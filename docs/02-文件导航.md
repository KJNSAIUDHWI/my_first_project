日常使用统一入口，底层训练器默认值不同，不能直接替换。旧run先看launch、exit_status、completion_check，再判断结果；旧格式缺success/candidate时按legacy处理，不因有权重文件就算成功。

### 当前权重怎样确定

共用入口通过 `model_registry.current(task)` 取权重，`paths.model_weight` 也转到该函数。有 `models/current.json` 中的任务登记时，读取登记路径并核对指纹；无登记时使用代码中的DEFAULTS。

CNN默认回退可指向具体历史版本，不等于发布别名。获授权部署时使用 `models/cnn/digit.pt`、`models/cnn/choice.pt`，保留历史版本。不能修改DEFAULTS绕过部署授权。

crop.py在执行时解析current('m1')并记录实际路径、指纹，导入时不解析。基础权重位置由paths.pretrained提供。

## 5. 哪些入口不能继续使用

| 入口或功能 | 应怎样处理 |
|---|---|
| m1至m4的build_dataset.py | 旧写入入口已停止；改用统一snapshot |
| m2/build_snapshot.py、common/dataset_builder.py及fixed_dataset的旧构建函数 | 已停止旧构建，部分纯函数保留供追溯 |
| CNN的build_digit_dataset.py、build_digit_legacy.py、build_choice_dataset.py | 历史生成脚本已停止，不能强行恢复写入 |
| tools/补多选区样本.py | 旧补样入口已停止 |
| common/choice_events.py及旧验证脚本中的C/D/G/I场景 | 改造前的实现或断言，现行流程不调用 |
| CNN新旧权重独立比较 | 尚无独立入口；训练指标不能代替 |
| 实际计分 | 尚无实现入口；识别答案不等于评分 |

新素材生成、未接通流水线等当前缺口集中写在01。需追溯旧命令或决定时读[06](06-历史.md)，使用前重新核对是否仍适用。
