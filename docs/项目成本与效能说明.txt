项目成本、标注规模与效能记录（可选阅读）
========================================

一、项目来历与开发方式
--------------------
本项目最初由一名电子信息类在读大学生发起，目标是做一套真正能落地的答题卡扫描识别与人工快速复核工具。

代码主要由 DeepSeek、GPT、Gemini 轮流编写，作者负责需求拆解、流程设计、数据审核与效果验收：
- 填空/实验大题必须拼成约 1500×1500 方图并发发送，才能把视觉大模型 API 成本压下来；
- 选择题答案必须无遮挡对照原卷，审阅页支持原地改框，低置信度必须精确标到具体题框；
- 题号不能串行、划掉的字不能算答案、局域网多人协同核对时不能撞车。

二、标注工作量与外包折算账本
--------------------------
模型可以先预标注画框，但歪框、漏框、多余框仍需人工逐张审核。
说明：本项目前期在本地私有迭代了较长时间，于 2026-10-25 起整理公开仓库；按 2026-11-03 的本地日志核对，M1 / M2 / M3 累计已审核结果共 85,234 个框（并非公开后 9 天内单靠肉眼突击完成）。

按实际向闲鱼询价的 0.09 元/框折算，若全部从零外包标注，账单如下：
- M1 版面分区      ： 7,763 框  ->    698.67 元
- M2 题号、选项    ：60,183 框  ->  5,416.47 元
- M3 大题及题号    ：17,288 框  ->  1,555.92 元
- 合计             ：85,234 框  ->  7,671.06 元

同期 API、算力与工具订阅支出约 805 元；日志可追溯或重建的手动改框共 11,459 次（含新增 2,150 次、调整 6,696 次、删除 2,613 次，同样按 0.09 元/次折算约 1,031.31 元）。

简单算一笔投入产出杠杆（仅供参考，未计入作者逐图浏览、流程设计与验收工时）：
- 资金杠杆       ：7,671.06 ÷ 805              ≈ 9.53 倍
- 标注修改杠杆   ：7,671.06 ÷ 1,031.31         ≈ 7.44 倍
- 合并折算       ：7,671.06 ÷ (805 + 1,031.31) ≈ 4.18 倍

三、实测识别速度与 API 费用
-------------------------
2026-11-01 对 10 页已转正高中物理答题卡连续测试（CPU FP32 · 豆包 Lite 非思考模式 · 4 并发）：
- 总耗时   ：36.8 秒（含首次模型加载）
- API 请求 ：14 次全部成功，0 结构失败
- 估算费用 ：约 0.045 元（约 4.5 元 / 千页）

200 页批量测试累计 1,432 条选择题、1,189 个填空大题、119 个身份区，244 批 API 请求估算费用约 0.66 元。
完整分阶段耗时与计费口径见 docs/性能测试.md。

说明：公开仓库仅保留以上汇总统计，真实试卷、训练数据与逐图审核日志均保留在本地。
