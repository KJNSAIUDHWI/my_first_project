# 运行环境

这里记录2026-10-31本机实际安装版本；完整版本快照在[04-环境版本.json](04-环境版本.json)。本次只读取版本并完成下述本机检查，没有重装、升级依赖或在全新环境安装验收。

## 环境与依赖

- Windows x64，Python 3.13.6；本机解释器`D:/Dev/Python/3.13.6/python.exe`。
- PyTorch 2.6.0+cu124、torchvision 0.21.0+cu124，torch构建CUDA版本12.4；这不代表驱动版本，也不证明既有GPU数值故障已解决。
- 常规推理、标注、离线评估及现有训练入口共用下列核心库实测版本。训练与推理职责不同，但目前不需要两套互相冲突的核心版本。
- 印刷题号适配器额外使用：PaddleOCR 3.7.0、PaddleX 3.7.2、ONNX Runtime 1.31.0；使用CPU ONNX，不要求安装PaddlePaddle。默认数字CNN未切换。
- 豆包Lite客户端已接通，使用标准库urllib；显式运行完整识别时调用。按用户要求，根目录.env明文保存ARK_API_KEY并排除Git跟踪；同名环境变量优先，密钥不回传页面。

## 新环境安装方法

整理不创建环境或依赖文件夹。下列命令仅供在用户指定的Python 3.13.6解释器中安装参考；本次没有执行安装，现有共享环境无需执行。

```powershell
$python = '<用户指定环境的python.exe>'
& $python -m pip install --extra-index-url https://download.pytorch.org/whl/cu124 torch==2.6.0+cu124 torchvision==0.21.0+cu124
& $python -m pip install ultralytics==8.4.96 numpy==2.3.5 opencv-python==4.11.0.86 Pillow==12.3.0 PyYAML==6.0.2 scipy==1.16.3 pandas==2.3.3 matplotlib==3.10.7 psutil==7.2.2 tqdm==4.67.1
# 仅需要Paddle印刷题号适配器时：
& $python -m pip install paddleocr==3.7.0 paddlex==3.7.2 onnxruntime==1.31.0 safetensors==0.8.0
```

Torch安装参考指定cu124 wheel索引及精确版本。若当前平台找不到对应wheel，停止安装并核对解释器/平台或原wheel来源，不自动替换成不同Torch/CUDA版本。核心版本清单不锁定全部传递依赖；全包版本快照仅供排查，不能当成跨平台可安装锁文件。

本机同时存在opencv-python及opencv-python-headless 4.11.0.86。上述参考只选opencv-python，避免两包共用cv2文件；本次未卸载现有包，清洁环境中的依赖解析与Paddle实际识别仍需另验。

## 本机验收与职责

`python -B tools/迭代.py --help`检查统一训练入口；`python -B pipeline/run.py --help`检查当前整页推理入口；`python -B tools/权重索引.py`只读核对现存权重。具体命令与训练准入规则见[05](05-迭代操作.md)。

入口帮助、固定名单、兼容保护和权重SHA检查不等于模型效果或GPU稳定性验收。真实数据不用于审核工具测试，训练需要新冻结快照且不能恢复已删除旧现场。

本机共享解释器的`pip check`报告：basic-pitch缺少tensorflow且resampy版本不满足其约束，pdfplumber缺少pdfminer-six。这些包不属于本项目依赖清单；因此不能把共享环境称为全包依赖检查通过。本次没有安装/卸载这些其他用途的包，建议后续安装使用用户指定的独立环境。

识别验收页使用标准库HTTP服务，默认127.0.0.1:8903。公式使用固定KaTeX 0.16.22静态资源；启动时若本次结果内没有资源，从官方npm包准备到结果目录，失败则保留原始公式文字并提示，不影响转录数据。
