# 迭代操作

本手册只写可重复的步骤。数据规则查00，当前配方、临时阻塞及实际run查01，工具实现查02。用户说业务目标，代理准备参数；下方占位变量不要求用户填写。

## 0. 现行入口速查

先按[04运行环境](04-运行环境.md)核对解释器与依赖。已接通与待交付边界见[07](07-交付状态.md)。

| 任务 | 入口 |
|---|---|
| 整页方向与M1推理 | `pipeline/run.py --input <图片目录> --out <新输出目录>` |
| 训练数据冻结、训练、状态 | `tools/迭代.py snapshot/train/status`，按下文使用显式任务与参数 |
| 检测、题号、涂黑人工审核 | `tools/标注工具/serve.py`、`tools/数字审核/serve.py`、`tools/涂黑审核/serve.py` |
| 现存权重及SHA只读扫描 | `tools/权重索引.py`；显式加`--write`生成索引，旧索引先备份到D盘codex目录 |

退休构建脚本仍在原有模块目录，由main中的停止保护拒绝执行；现行训练使用统一入口，不提供force绕过旧保护。

## 1. 先确定这一轮要解决什么

明确目标错误、任务、数据范围和比较标准，再选入口。m1整页定位，m2选择内部定位，m3填空内部定位，digit/choice分别识别题号与涂黑。不因01列有问题就全部开工。

PowerShell在项目根目录执行；使用已核实的Python。每轮建立新run，已有快照不覆盖。当前训练配方记录在run，不复制脚本来代表新版本。

```powershell
$python = 'D:/Dev/Python/3.13.6/python.exe'
# $task、$run、$stage和各名单由代理按本轮目标准备。
& $python -B tools/迭代.py --help
```

核对实际子进程环境，不能用监督进程的Python/PyTorch版本代替。工具不支持的参数先查子命令--help，不透传替换数据来源。

## 2. 准备图片和预标注

已有素材先查来源、方向、父页身份、审核状态及分区。写入前保护已审数据和页面草稿；结果先暂存核查，预测始终待人工审核。

| 任务 | 入口与用途 |
|---|---|
| M1 | pipeline/m1/pred.py，默认补无标签图；--all仅重打未审，不支持subset |
| M2 | pipeline/m2/pred.py --subset <本批CSV>，可显式--weights；已有事件拒绝重打 |
| M3 | pipeline/m3/pred.py --subset <CSV> --weights <永久候选>；基础入口不含跨设备guard，是否可用先查01 |
| 整页裁M2 | pipeline/cascade/crop.py --parent-list <父页CSV>，不是M3生成器 |
| CNN增量 | pipeline/cnn/prepare_increment.py --batch <新批次> --check-only，核对后去掉检查开关 |
| 重裁未审数字 | pipeline/cnn/refresh_digit_crops.py --data <旧未审批次> --batch <新批次> |

原始扫描已清理时，整页裁M2使用保留的M1工作图并核对sampling中的working/oriented指纹；原始路径仅保留作来源追溯，不要求文件仍在。工作图缺失或指纹不符仍须停止。方向确认工具需要重新提供原始扫描目录，不能把缺raw当成没有工作数据。

具体阈值、输入大小、设备和补边必须与拟用权重的工作规格一致，在产物中记录；更换输入处理要回归真实错例。遇到已有产物拒绝覆盖时查原因，不删除保护文件重跑。

API预标注/复核是独立的可选流程，不属于默认训练步骤。仅在当前明确授权且接口未暂停时使用；grid_prelabel、verify_digits、choice_grid_review_all等入口通过各自--help查询。先小批验证编号、标签范围、截断、失败重试与完整性，再冻结名单处理；请求与用量结果留实际批次，密钥仅从环境变量读。接口建议和多数票不能直接写成人审结论，不能按旧授权重启已暂停接口。

## 3. 请用户审核本轮图片

核对已有服务和端口后再启动，浏览器用Edge。检测可用：

```powershell
& $python -B tools/标注工具/serve.py --data (Join-Path 'data' $task) --subset $reviewList --port $port
```

数字、涂黑入口见02，各库参数查--help。提交、分类、草稿和特殊样本语义统一见00，不在此复制。检查服务API可用与页面可用是两件事；受阻如实报告，不换执行者绕过。

## 4. 准备这一轮的准入范围

```powershell
$snapshotArgs = @('snapshot', '--task', $task, '--run', $run)
```

检测显式追加本轮stage及已审subset；需要暂缓/特殊决定时追加defer-list/decisions。M1/M2通常按阶段1至4，旧stage0或其他批次先核对实际身份与入口。CNN不传stage/subset/defer-list。明确排除坏训练标签才用skip-invalid，明确授权推断数字才用allow-inferred。

同名subset在预标注表示本批预测，在审核表示本批浏览，在snapshot表示必须检查的名单；检测快照仍累计接入指定stage及以前数据。裁图parent-list限定父页，不混用。

## 5. 先检查，再冻结

```powershell
& $python -B tools/迭代.py @snapshotArgs --check-only
if ($LASTEXITCODE -ne 0) { throw '数据检查失败' }
& $python -B tools/迭代.py @snapshotArgs
if ($LASTEXITCODE -ne 0) { throw '快照生成失败' }
```

两次使用同一参数。检查失败先处理真实标签、身份或名单，不通过扩大暂缓、换验证集来凑通过。核对数量、分区、父页、排除项和验证基线，快照必留文件见00。后续改标不回写已冻结标签；旧run不补造缺失审计。

## 6. 训练，并确认监控显示本轮

先核对起点、轮数、早停、学习率、架构、输入和设备。继续候选显式--initial；结构改变使用匹配的官方底座，不拿旧小架构冒充大架构。CNN只有明确从头训练才用--scratch，起点失效不自动随机初始化。统一入口不支持恢复原优化器。

```powershell
& $python -B tools/迭代.py train --task $task --run $run
& $python -B tools/迭代.py status --run $run
```

实际配方的--epochs/--batch/--lr/--initial等参数由代理补齐；支持范围查train --help，不能用本手册的省略示例冒称已选配方。数值保护始终开启，诊断用的no-amp/deterministic/no-cudnn各自改变计算路径，不等于修复根因。显式设备失败不自行改CPU长训。

M3可显式加`--range-aware`做DFL范围约束分配实验，默认关闭。它只改变训练正样本分配，验证和推理解码保持原实现；使用前核对结构和输入尺寸，比较同名单的漏检与内容覆盖。代码在所有预测层都无法表示某真值时停止，不会静默丢弃该框。该选项不代表任何已有候选已部署。

监控固定http://127.0.0.1:8901/，先查已有进程，必要时：

```powershell
& $python -B tools/训练监控/serve.py --run (Join-Path 'train' $run)
```

Edge核对实际run。CSV指标只在整轮验证后更新，日志步数和心跳另看；页面刷新不等于训练推进。警告面板只作定位，不能替代退出码及完整性检查。更新监控仅重启监控，不中断训练或刷新审核草稿。

## 7. 检查候选，再比较效果

核对exit_status、completion_check、权重可加载/有限值/BN及候选来源。AMP可恢复溢出、致命数值错误、自然结束、人工停止分别记录；人工停止保留原退出结果并单列manual_stop检查，不改报完整训练成功。

在相同名单、标签和推理口径比较新旧权重。pipeline/m1/eval.py可评估匹配类别的检测快照，但当前固定GPU0、没有device选项，不能称CPU评估。显式结果目录必须新建；CPU FP32或特殊结构评估需落实单独可核查入口后执行。参数与结果保存在报告，不塞回通用手册。

CNN用pipeline/cnn/eval_choice.py等同快照评估；整页链路用pipeline/eval_chain.py，参数查--help。英语专项实验须同名单同预处理，专项权重不走通用部署。报告说明参与选模与否，不能把固定验证或训练回测称为独立测试。

训练结束永久留档。停止后精简/清理检查点先核对候选、故障证据、当前部署和使用状态，写compaction/pruning；已删旧best/last按记录追溯永久候选。第二轮按SHA删除了部分重复训练权重，原路径与保留文件对应见models/清理/20261031_第二轮彻底清理_1303/weight_mapping.json；历史run的initial/best/last路径可能已失效，新任务须使用映射中的保留文件，不恢复已删现场。移除优化器不改变模型参数，但不再支持原优化器恢复。

用户明确授权“权重加最小记录”收尾时，先保存删除清单、权重SHA、参数/来源/成绩/退出信息及固定验证名单，再清理快照、日志和故障输入。清理后旧run不能直接续训或按旧快照重评，后续训练须从当前人工记录新建独立快照；不把本次删除操作扩展到models永久候选和对比报告。

## 8. 用户同意后才部署

先给出候选、同口径比较及风险，用户明确同意后：

```powershell
& $python -B tools/迭代.py deploy --task $task --run $run
```

工具核对任务/run/路径/指纹，再更新别名和current.json。status可部署不代表获准；旧legacy缺记录不能直接部署。只改文件名不是换模型，须同步引用并核对哈希，不用覆盖权重绕过登记。

## 9. 失败后从哪里查

| 现象 | 核对依据 |
|---|---|
| 未审/标签/特殊报错 | 逐图日志、原图和本轮准入名单 |
| 身份或验证变化 | manifest、splits、固定基线和父页 |
| NaN/异常预测 | numerical_failure、故障批次、同输入重复与独立参照 |
| 退出却无候选 | exit_status、completion_check、manual_stop |
| 加载错误 | 实际路径、指纹、架构和起点 |
| 页面不更新 | 当前run、接口、日志与进程心跳 |

保存故障证据，结论和下一步限制写01，具体经过留run/报告；解决后从当前接力移出，必要时写阶段事件。不按异常框数截断结果或填零掩盖错误。

## 10. 保存进度和换窗口

01使用结构3，只保存接手需要的状态：

```text
接力结构：3

当前状态：
- 当前结果与工作范围。

本轮限制：
- 只在当前阶段有效、尚未解除的限制；长期规则引用00。

待办与阻塞：
- 尚缺什么，不代表用户已授权全部执行。

证据入口：
- 实际run、报告或规则路径，不复制完整日志。
```

不再使用全局编号、关闭清单和累计决定。长期决定更新00或相应文档；本阶段完成事项离开01。重大变化用--event写一句事实和证据入口，普通更新不必写历史事件。会话ID同窗口复用，summary放本次D盘codex目录。

```powershell
$before = & $python -B tools/写快照.py --inspect | ConvertFrom-Json
if (!$before.parse_ok -or !$before.history_ok) { throw '先处理记录异常' }
$argsNote = @('--session', $session, '--note-file', $summaryPath, '--expected-sha256', $before.sha256)
& $python -B tools/写快照.py @argsNote --dry-run
if ($LASTEXITCODE -ne 0) { throw '预检失败' }
& $python -B tools/写快照.py @argsNote
```

用户要求换窗口：先核对事实和长期规则去向，预检/提交均加 `--handoff --event <本阶段变化摘要>`，读回01并inspect确认archived=true、SHA与返回一致，再回复“交接完成”。工具将独立快照留在docs/history/snapshots，06只生成链接。普通更新不存整份历史；确需留阶段结果用--event。首次结构2转3加migrate-legacy，仅迁移用一次。

并发哈希不符要重读合并，不能只换哈希强写。归档失败时01可能已保存，先inspect再以同会话/正文/事件重试补档；重复提交不增加事件。工具不能判断事实是否遗漏，代理须读回核对。维护工具运行：

```powershell
& $python -B tools/验证交接与准入.py --workdir (Join-Path $scratch '交接验收')
```

仅在临时假项目验证，不写正式数据。CNN数据流回归使用pipeline/tests/test_data_flow.py；不把模拟交接通过称为真实训练或浏览器验收。

## 识别与人工可视化验收

在根目录使用既定Python。识别和人类反馈独立于训练审核，不自动产生训练标签。

```powershell
& 'D:/Dev/Python/3.13.6/python.exe' -B pipeline/run.py --recognize --out '<本次结果目录>'
& 'D:/Dev/Python/3.13.6/python.exe' -B tools/识别验收.py --dir '<本次结果目录>' --port 8903
```

默认沿用固定20页物理名单；新扫描目录加`--input`，已转正工作图加`--working-images`以防再次旋转。默认CPU FP32、Paddle题号、high方形拼图与4并发；`--detect-only`仅生成本地结果与拼图，不调用API。标准答案、评分和成绩导出本轮不接。

根目录.env按用户要求明文存`ARK_API_KEY=...`并排除Git；环境变量优先。不要把密钥写入命令日志、报告或页面。凭据错误停止后续请求，限流退避；同输入/模型下重复运行复用成功响应，仅结构异常图块额外进行一次定向补跑。

用Edge打开 http://127.0.0.1:8903/ ，左右两栏独立滚动；原卷滚轮缩放、拖动平移、双击放大，左侧“整卷复位”（快捷键F）始终可见。选择题答案默认直接标在卷面，可关闭；填空按小题一行紧凑展示，可筛选只看填空/选择题。先看整页有无漏检，再看逐题裁图和转录；可按异常/未检查筛选，点击原卷框定位、查看实际拼图。人类可标正确/识别错误/漏题漏空/对应错误/看不清并填写修正，点击保存；反馈位于结果目录的feedback.json及历史日志，重开继续，不回写data。多窗口并发修改会拒绝旧版本并保留草稿。

开发测试使用`pipeline/tests/test_recognition.py --temp <D盘codex假库目录>`；前端`test_recognition_ui.cjs`使用临时linkedom模拟DOM，不能代替真实Edge交互验收。

含图舍弃规则：按用户决定，任何带图片/示意图/曲线等图形的小题整体舍弃，仍保留小题号。API在该小题下输出保留标记`{"舍弃":"舍弃"}`，它不是第1空，也不表示空位数量；页面显示“含图，整小题舍弃”。同小题不混入其他答案，其他无图小题继续。更换提示词后不复用旧语义的API缓存；性能测试分别记录中止旧轮和正式新轮费用。
