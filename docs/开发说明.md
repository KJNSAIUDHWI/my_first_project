# 开发说明

## 目录

| 目录 | 内容 |
|---|---|
| `pipeline/` | 检测、转录、模型读取、训练及回归测试 |
| `tools/` | 识别验收、标注审核、训练监控及统一迭代入口 |
| `weights/` | 当前部署加密分卷、哈希清单和恢复说明 |
| `docs/` | 公开使用、架构、开发和性能文档 |
| `models/` | 解压后生成的部署模型和注册表，Git忽略 |
| `data/`、`train/` | 本地数据和训练产物，Git忽略 |

仓库不附带内部回归名单、训练数据和人工审核记录。

## 实现入口

| 功能 | 文件 |
|---|---|
| 完整识别与运行参数 | `pipeline/recognize.py`、`pipeline/run.py` |
| 拼图、提示词、API调用、响应校验 | `pipeline/common/recognition_api.py` |
| 题号与选项配对 | `pipeline/stages/match.py` |
| 答题行裁图与选择题结果 | `pipeline/stages/choice.py` |
| 印刷题号 | `pipeline/cnn/printed_number.py` |
| 涂黑读取 | `pipeline/cnn/choice.py` |
| 部署模型解析 | `pipeline/common/model_registry.py` |
| 可视化验收 | `tools/识别验收.py`、`tools/识别验收.html` |
| 标注与训练监控 | `tools/标注工具/`、`tools/训练监控/` |
| 训练快照与模型迭代 | `tools/迭代.py` |

完整识别模式始终通过当前部署注册表解析权重，校验已登记模型的SHA。没有登记的任务使用代码中的默认路径。替换模型时同步维护注册表和权重包。

## 测试

安装依赖后，可先运行不需要试卷数据的回归：

```powershell
python -B pipeline/tests/test_choice_matching.py -v
python -B pipeline/tests/test_choice_sequence.py -v
python -B pipeline/tests/test_printed_number.py
python -B pipeline/tests/test_chain_report.py -v
python -B pipeline/tests/test_eval_chain.py -v
```

其他测试覆盖API并发和恢复、反馈保存、前端交互、训练快照及数值保护。部分维护测试要求显式临时目录、假数据或本地模型，请按对应脚本参数运行；不要直接对真实审核库执行测试。

修改转录逻辑时检查图块映射、同题号跨页面、空位保留、并发乱序和中断恢复。修改页面时检查原卷缩放平移、Esc返回、筛选与滚动、反馈草稿和错误提示。

## 训练与模型管理

统一迭代入口提供 `snapshot`、`train`、`status`、`deploy` 等子命令：

```powershell
python -B tools/迭代.py --help
python -B tools/迭代.py snapshot --help
python -B tools/迭代.py train --help
```

训练需要自行准备已审核数据、固定分区和所需基础模型；发布的部署权重包不包含训练快照或全部预训练底座。旧的 `build_dataset.py` 等写入入口已有退休保护，使用统一快照流程。

模型预测、API结果和人工训练标签保持分离。新候选先评估、留档，再显式切换部署。检测与CNN训练代码包含非有限值和梯度保护，修改训练流程时一并运行对应回归。

## 提交内容

源码、公开文档及加密部署分卷可进入Git。API密钥、试卷、人工反馈、原始训练日志和临时产物留在本地。更新权重包时同步分卷哈希、部署清单和恢复说明。
