二、CMD 一键恢复方法
在项目根目录打开 Windows CMD 或 PowerShell，直接执行：

  python tools\下载权重.py

脚本会自动：
  1) 从百度飞桨官方源下载并校验 PP-OCRv6 到 models/pretrained/PP-OCRv6_medium_rec_onnx/；
  2) 从 GitHub Releases 下载 autograde_weights_v20261127.7z 到 weights/ 并校验 SHA256；
  3) 提示输入密码并用本机 7-Zip 自动解压到 models/ 目录。

三、手动解压方法（如已在浏览器手动下载附件放到 weights/ 目录）
  1) 拉取官方 PP-OCRv6：
     python tools\下载权重.py --only-paddle
  2) 解压自训权重（或直接打开「自动改卷工作台.exe」点「输入密码解压加密权重」）：
     "C:\Program Files\7-Zip\7z.exe" x weights\autograde_weights_v20261127.7z -o.

详细 SHA256 校验值见同目录 SHA256SUMS.txt 与 部署清单_20261127.json。
